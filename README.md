# Task 02 — Schema Design

## Overview
A normalised database schema (3rd Normal Form) designed for a small business e-commerce/retail problem[span_2](start_span)[span_2](end_span).

## Tables Included:
1. **customers**: Stores client information.
2. **products**: Stores item details and inventory stock.
3. **orders**: Tracks purchases made by customers with foreign key reference.
4. **order_items**: Bridge table holding individual product quantities per order.

## How to Run:
Run the `schema.sql` script in any SQL database engine to create the normalised tables with proper primary keys, foreign keys, and constraints[span_3](start_span)[span_3](end_span).
